

# Jaspersoft Studio (Community Edition)

Jaspersoft® Studio es un software de edición para JasperReports®. Le ayudará a diseñar y ejecutar plantillas de informes; crear consultas de informes; escribir expresiones complejas; y disponer componentes como más de 50 tipos de gráficos, mapas, tablas, tablas cruzadas y visualizaciones personalizadas. Se integra con JasperReports® Server para crear potentes flujos de trabajo de informes.

Puede crear documentos de cualquier complejidad a partir de sus datos. Desde PDF listos para imprimir hasta HTML dinámico e interactivo con navegación dentro o fuera del informe. Documentos de alta calidad en PowerPoint, RTF, Word o hojas de cálculo, o datos en bruto en CSV, JSON o XML. No es difícil crear un exportador personalizado para adaptarse a cualquier necesidad.

Son accesibles diferentes tipos de orígenes de datos: big data, CSV, Hibernate, Jaspersoft Domain, JavaBeans, JDBC, JSON, NoSQL, XML u orígenes de datos personalizados.

Disponible como un complemento de Eclipse o como una aplicación independiente, se ofrece en dos ediciones: Community y Professional. La edición Professional incluye características adicionales, mapas, gráficos avanzados en HTML5 y soporte profesional.
